放課後の黒板 だより学級通信

第1号
発行：日直

教室のうしろの黒板って、休み時間に誰かが落書きして、次の日の朝にはきれいに消えてますよね。 この掲示板はそれをそのままネットに持ってきました。書いたことは毎朝5時に全部消えます。 だから、どうでもいいことを気軽に書いてください。

使い方

  1. 下のチョーク置き場からチョークの色を選ぶ
  2. 書きたいことを書いて「黒板に書く」
  3. いいなと思ったら「わかる」を押す。正の字で数が増えます
  4. 返事をしたいときは「書き足す」

チョークの色

  • 白 … ふつうの話・雑談
  • 黄 … 質問・教えてほしいこと
  • 赤 … 急ぎ・みんなに知らせたい
  • 青 … 部活・行事・イベント

この黒板のきまり

  • 名前・学校名・電話番号・メール・SNSのIDは書けません（書こうとすると止まります）
  • 悪口は書けません。いやな書き込みは「先生に言う」で通報。3人が通報すると見えなくなります
  • 写真の位置情報（GPS）は、貼るときに自動で消しています
  • 自分の書き込みを消したいときは、書くときに「消しゴム番号」を決めておいてください
  • その日いちばん最初に書いた人が、黒板の右はしに日直として書かれます
授業中に書くと「授業中」のハンコが押されます。
バレても日直は責任をとりません。
